# Kinara 1.0.2

## Back after sleep, every time

- **Finds the trackpad again after waking.** On some Macs, a MacBook Air M1 among them, macOS brings the trackpad back from sleep as a new device. Kinara kept trying the old one, so gestures stayed off until it was reopened, and Retry didn't help. Now Kinara looks for the trackpad again whenever the old one doesn't answer. ([#3](https://github.com/0x1p0/kinara/issues/3))
- **Waits for a slow trackpad.** If the trackpad takes a moment to come back, Kinara keeps trying for about half a minute, showing "Waiting for the trackpad…", instead of giving up at once.
- **Haptics reconnect too.** The strongest haptic ticks come back if they stop answering after sleep.

Nothing changes on Macs that already woke up fine.

Kinara is signed but not yet notarized by Apple, so the first launch of a fresh download needs **System Settings → Privacy & Security → Open Anyway**.
