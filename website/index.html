☀Display & keyboardFind your comfortable light.05
Display brightness
Up brightens; down dims the built-in display. It can follow the pointer to Apple displays and to other monitors over DDC/CI where they support it.
Keyboard backlight
Up brightens; down dims a supported backlit keyboard. macOS and ambient-light conditions can limit changes.
Night Shift warmth
Up warms the display; down cools it, and zero turns Night Shift off. Uses a private macOS interface that can change.
True Tone
Up turns True Tone on; down turns it off. Only on displays that support it.
Extra dim
Dim below the lowest backlight level for late nights. Quitting Kinara always restores normal brightness.
♪Audio & microphoneA little more control over your sound.08
Output volume
Up raises; down lowers the default audio output. Requires a device with software volume control.
App volume
Change only the sound of the app in front. macOS asks once for System Audio Recording; Kinara never records or saves audio. macOS 14.2+.
Mute app in front
Down mutes only the app in front; up unmutes it. A tap toggles. It stays muted until you unmute it. macOS 14.2+.
Solo app in front
Up plays only the app in front and silences the rest; down ends solo. A tap toggles. macOS 14.2+.
Switch audio output
Up picks the next output, down the previous one. The indicator names the new device.
Microphone level
Adjust the default input’s gain without recording audio. Changing gain never unmutes the device.
Speaker mute
Down mutes; up unmutes the default output. Available when the device provides a hardware mute control.
Microphone mute
Down mutes; up unmutes the default input, when readable, writable hardware mute is available. Other inputs and app mute buttons stay separate.

SIMPLE UP FRONT. FLEXIBLE UNDERNEATH.

Make it feel like you.

A few good defaults. Plenty of room to make them yours.

Gestures & edge zones

Pick Everyday, Precise, or One finger. Assign any of the 26 actions, or Off, independently to each edge. Set side widths from 1–40%, sensitivity, direction, and the distance needed to activate a gesture.

One-finger mode also offers an optional top edge, from 1–30% high, with horizontal or vertical gestures and configurable actions.

Palm protection & safe testing

Kinara checks starting position, finger count, movement, timing, and typing activity before accepting a gesture. Tune the intent checks and typing protection to suit your hands.

The safe test view explains which rule accepted or stopped a gesture, including contact count, distance, straightness, and duration. It never executes an action, sends a shortcut, or changes hardware. Lift all fingers before trying again.

Volume, brightness & haptics

Set minimum and maximum comfort levels, configure mute behavior, or use Undo after a volume or brightness adjustment. Undo does not reverse microphone changes or shortcut actions. Menu bar sliders are still available when gestures are paused.

Choose Soft, Standard, or Crisp native haptic patterns, taps at 2%, 5%, or 10% steps, and an optional gesture-start tap. Try the feedback in Settings. These are patterns, not a hardware strength dial; what you feel depends on your trackpad and macOS.

Appearance & everyday shortcuts

Follow the system theme or choose light or dark. Show an icon, Kinara’s name, volume, or brightness in the menu bar, and customize the on-screen indicator. Native Liquid Glass is used on macOS 26+, with translucent materials on earlier versions and support for Reduce Motion and Reduce Transparency.

Launch at login, exclude apps, set a pause shortcut, and choose whether Kinara appears in the Dock while windows are open. Closing the last window can hide its Dock icon while menu bar controls keep running. Reopen from Spotlight if your menu bar is crowded.

Settings, help & software updates

Search the organized settings categories to find what you need. Reopen the setup guide at any time, reset gesture preferences, or open a separate Controls window.

Check for updates manually or once a day. Download and install from the app when you’re ready. Update signatures verify authenticity; they do not mean the app is Apple-notarized. Update checks contact GitHub, which can see your IP address and app version.

GOOD TO KNOW

Small questions.
Clear answers.

Ask 0x1p0 on GitHub
Will Kinara work on my Mac?

Kinara supports macOS 13 Ventura and later on Apple silicon and Intel Macs, with a compatible Apple Multi-Touch trackpad. Haptics require a Force Touch trackpad. Touch support uses Apple’s private MultitouchSupport framework, so compatibility can change with OS or hardware updates.

What about external displays and audio?

Brightness controls the active built-in display; external monitor brightness via DDC isn’t supported. Volume works with audio outputs that allow software volume control. Some digital outputs have a fixed level.

Does microphone mute work everywhere?

No. Kinara controls only the current default input, and hardware mute is offered only when its driver supports reading and changing it. Other inputs and a meeting app’s mute button are separate. Setting input gain to zero is not the same as muting. Kinara never opens a recording stream, and adjusting gain never unmutes the device.

Will every action work with my setup?

The action library explains what each option needs and marks unsupported hardware controls. Keyboard backlight requires a supported keyboard; ambient light and macOS may limit it. Window, navigation, and tool actions send standard shortcuts, so behavior depends on your app, keyboard layout, and enabled macOS shortcuts.

Continuous controls follow your swipe. Repeating commands use movement thresholds and rate limits. Other commands run once per swipe, then wait for a full finger lift. Commands stop if the foreground app changes.

Why does it need Accessibility access?

Accessibility lets Kinara recognize edge swipes and prevent accepted gestures from also scrolling your page. It also lets Kinara send the keyboard shortcuts you assign. You can use the menu bar sliders without it. The setup guide is always available in Settings → About & help.

Is it free? Does it collect my touch data?

Yes, Kinara is free to download. Touch data is processed locally and isn’t stored. There’s no app account. Optional update checks contact GitHub for release information; they do not upload your gestures. The source is available on GitHub.

This website has no added analytics or advertising trackers. It is hosted on Vercel and requests public release information from GitHub to keep the download button current; those services receive normal connection information such as your IP address.

How do I update or get help?

Open Software updates in Kinara to check and install a signed update. You can also download a fresh copy from GitHub Releases. For setup help, reopen Getting Started from the menu or Settings. Found something off? Let 0x1p0 know on GitHub.
